Mode d'emploi

Annoter : touche ＋, puis touche le plan à l'endroit exact (zoome d'abord pour être précis). Tu peux retoucher ailleurs pour corriger, puis « Valider ». Écris le texte, ajoute photos ou vidéo, « Enregistrer ».

Rouvrir : touche un repère numéroté, ou ☰ pour la liste complète.

Hors ligne : ouvre le site une fois avec du réseau (Wi-Fi ou 4G), puis dans Safari touche Partager, puis « Sur l'écran d'accueil ». L'icône « Relevé MDLC » s'ouvre ensuite sans réseau dans l'atelier. Tout est enregistré dans le téléphone au fur et à mesure.

Récupérer sur le PC : Menu, « Exporter vers le PC ». Envoie le ZIP par AirDrop, mail, OneDrive ou « Enregistrer dans Fichiers ». Sur le PC, dézippe et ouvre synthese.html.

Sauvegarde : les données restent dans le téléphone (pas sur internet). Exporte régulièrement : si Safari efface ses données, l'export permet de tout réimporter.
