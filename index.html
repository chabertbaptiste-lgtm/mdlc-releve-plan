Mode d'emploi

Annoter : touche ＋, puis touche le plan à l'endroit exact (zoome d'abord pour être précis). Tu peux retoucher ailleurs pour corriger, puis « Valider ». Écris le texte, ajoute photos ou vidéo, « Enregistrer ».

Rouvrir : touche un repère numéroté, ou ☰ pour la liste complète.

Cotation : ouvre une annotation, touche « 📏 Cotation », puis touche le second point sur le plan (mur, machine, poteau) et « Valider ». Tape ta mesure réelle en mètres. Dès que tu as saisi quelques cotes, l'appli déduit l'échelle du plan et te propose la distance calculée pour les suivantes.

Qualité : les photos sont gardées telles quelles. Pour les vidéos, l'iPhone recompresse celles choisies dans la photothèque : pour l'original, touche « Fichiers » puis « Choisir un fichier » (enregistre d'abord la vidéo dans l'appli Fichiers depuis Photos, Partager, « Enregistrer dans Fichiers »).

Hors ligne : ouvre le site une fois avec du réseau, puis dans Safari touche Partager, puis « Sur l'écran d'accueil ». Tout est enregistré dans le téléphone, rien ne part sur internet.

Récupérer sur le PC : Menu, « Exporter vers le PC ». L'export est découpé en paquets ZIP : envoie chaque paquet (AirDrop, câble, mail). Sur le PC, ouvre ce même site, Menu, « Importer des paquets », et choisis tous les ZIP. Tu peux aussi dézipper tous les paquets dans un même dossier et ouvrir synthese.html.

Sauvegarde : exporte régulièrement. Si Safari efface ses données, les paquets permettent de tout réimporter.
